# Portfólio de Cayke Vilani

<!-- Este arquivo documenta o objetivo, a estrutura e a execução do projeto -->

Este projeto é um portfólio pessoal desenvolvido em HTML e CSS para apresentar informações sobre mim, meus projetos, tecnologias e canais de contato.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Devicons

## Estrutura do projeto

- `index.html` — página inicial
- `sobre.html` — página sobre mim
- `projeto.html` — página de projetos
- `contato.html` — página de stack e contato
- `css/style.css` — estilos do site
- `Images/` — imagens utilizadas no portfólio

## Como executar

1. Baixe ou clone o projeto.
2. Abra qualquer arquivo HTML em seu navegador.
3. Para uma melhor experiência, use um servidor local, como o Live Server do VS Code.
